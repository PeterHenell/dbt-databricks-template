# Dev profile at the repo root, prod profile in `deploy/`

dbt looks for `profiles.yml` in the current directory before `~/.dbt/`. We use that: each developer's profile is generated by `make setup` as a gitignored `profiles.yml` at the repo root, so local runs pick it up with no flags. The committed prod profile lives in `deploy/profiles.yml` and is used only when the deployment passes `--profiles-dir deploy`. Neither profile can be picked up in the other's context by accident. Don't move the prod profile to the repo root: it would replace every developer's dev profile.
